# RAG From Scratch - Learning Content

This repository contains our learning materials for understanding and implementing Retrieval Augmented Generation (RAG) from scratch.

## Overview
Retrieval augmented generation (RAG) has emerged as a popular and powerful mechanism to expand an LLM's knowledge base, using documents retrieved from an external data source to ground the LLM generation via in-context learning. These notebooks and resources build up an understanding of RAG starting with the basics of indexing, retrieval, and generation.
